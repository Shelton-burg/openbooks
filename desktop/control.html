Let’s set up your books

Create the owner account for this computer. Your password stays on this computer; no email or payment is required.

Use at least 14 characters. This creates an empty business. You can import and check your existing books afterwards.

Your desktop is ready

The application opens in your normal browser. It is accessible only on this computer.

Open my books

Closing a browser tab leaves TradeDesk running. Backups run while the application and computer are on. Use the desktop shortcut to reopen it.

Backups and receipts

A backup includes all businesses, accounts, books and original receipts on this installation. Each file is checked before the backup is marked complete.

The default folder is on this computer. Choose an external drive or copy backups elsewhere to protect against losing the computer. Backups contain private information and are not encrypted by this app. Older backups are kept until you remove them.

Restore a saved backup

This replaces all businesses and accounts on this installation. TradeDesk first saves the current data, verifies the chosen backup, then restores it. Everyone must sign in again.
