OPENBOOKS · SELF-HOSTED

Your books, on your Windows computer.

This installer includes the runtime and application. You do not need Node, Docker, an AI account or a monthly software subscription.

Unsigned beta for pilot testing. The installer has been cross-compiled and its application tested on Linux. Windows installation, desktop launch, upgrade and uninstall still need a Windows pilot. Keep your existing accounting system during testing. No independent security or accountant certification is claimed.

Install and start

  1. Use the installer supplied by the project owner. Windows may show an unknown-publisher or SmartScreen warning because this beta is not digitally signed. If Windows or your organisation blocks it, stop and request a signed build; do not disable security controls.
  2. Run the installer. It installs for your current Windows account without requiring administrator rights.
  3. Choose whether to start quietly when you sign in to Windows. This is optional and off by default.
  4. Select Open OpenBooks on the final screen. Your normal browser opens the first-run wizard.
  5. Enter your business, name, email and a password of at least 14 characters. Then sign in and check your business settings before importing records.

Everyday use

Open the OpenBooks desktop shortcut. The application uses http://127.0.0.1:38471 and is accessible only on this computer. This does not publish your books online or give other computers access.

Closing the browser leaves the app running. From the Start menu, open OpenBooks → Desktop controls and backups to manage it, or Stop OpenBooks to stop it.

Backups

Desktop controls provides Back up now, a backup-folder setting and Restore selected backup. Daily backups run while the app is running; a sleeping or switched-off computer cannot run them. The app checks for an overdue backup on startup and periodically afterwards.

A full backup covers every business, user account, financial record and original receipt on this installation. Files are checked before success is reported. The automatic run also attempts the existing business snapshots and recurring draft generation. It never posts invoices or sends emails. Any maintenance failure appears in Desktop controls.

The default backup folder is on this computer. Choose an external drive or copy completed backup folders elsewhere. Keep each folder intact, including manifest.json and data. Backups are not encrypted by this application and contain private financial records and password hashes; protect the drive. The app does not automatically delete old backups.

Restore

Choose a saved backup in Desktop controls and type RESTORE. This restores the whole installation, including all businesses and users. The app verifies the backup, saves the current data, stops the accounting process, restores the chosen data and restarts. Existing sessions and outstanding invitation links are revoked. Sign in with the password that applied at the time of the backup.

The previous data directory is retained separately and its location is displayed. If restoration fails, do not delete retained folders. Ask the maintainer for recovery help.

Where data lives

  • Application: %LOCALAPPDATA%\Programs\OpenBooks
  • Books and receipts: %LOCALAPPDATA%\OpenBooks\data
  • Default backups: %LOCALAPPDATA%\OpenBooks\backups
  • Startup/error log: %LOCALAPPDATA%\OpenBooks\desktop.log

These locations are separate so reinstalling or uninstalling the app retains your books. They are private to your Windows profile under normal Windows permissions. This app does not encrypt the live database; use appropriate device protection.

Updates and uninstalling

Updates are manual. Run a newer installer from a trusted source. The existing app must stop and complete a verified backup before its application files are replaced. If this fails, the update stops. There is no silent download or auto-update service.

Uninstall through Windows Installed apps. Uninstalling removes application files and shortcuts, and leaves data and backups intact. Reinstalling for the same Windows account uses the retained data. Do not uninstall by deleting random data folders.

Limits and troubleshooting

  • 64-bit Windows 10 or newer; Windows 11 recommended. ARM64-native and 32-bit installers are not included.
  • No payroll, live bank feeds, tax lodgment, card-payment integration or automatic email delivery. AI/email providers are off in the desktop package.
  • Do not move the live database into a shared network or cloud-sync folder. Back up completed snapshots instead.
  • If port 38471 is in use, close the conflicting application and reopen OpenBooks. The launcher does not silently connect to another service.
  • If setup or launch fails, inspect the desktop log. Do not share session files, full backups, receipts or passwords in public bug reports.
  • For a forgotten password, contact the installation maintainer; desktop password-reset UI is not included in this beta.
